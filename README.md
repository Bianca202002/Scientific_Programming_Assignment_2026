# Scientific_Programming_Assignment_2026

This study aims to answer the question: "Does an increase in the CD34+ cell dose relative to the recipient's body weight improve survival in children without an acute or chronic risk of graft-versus-host disease (GvHD)?" To answer this research question, I used the Cox Proportional Hazards Model and the Kaplan-Meier estimator for survival analysis, and logistic regression for the second part of my research question.

# How to run this code

The code is a Jupyter Notebook. To run it, simply open it in VS Code, select the Python kernel (version 3.13.9), and run the code cells. This notebook assumes that the `bone-marrow.arff` file is in the same folder as the notebook.

To obtain the dataset, go [here](https://doi.org/10.24432/C5NP6Z)
